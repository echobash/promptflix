## What is this?

Most prompt libraries are a giant unsorted dump. promptflix is different.

Every prompt is organized by **who you are** — so a developer, a teacher, a founder, and a 10-year-old can all land here and find exactly what they need in seconds. Role-based. Free. Forever.

## Features

- 🔍 **Live search** — filter by keyword across all prompts instantly
- 🏷️ **Category chips** — jump to any role in one click
- 📋 **One-click copy** — prompt goes straight to your clipboard
- ✏️ **Edit before copy** — tweak any prompt in the modal before running it
- 🎨 **6 themes** — Cinema, Aurora, Sunset, Emerald, Rose, Ocean
- 📱 **Fully responsive** — works on mobile, tablet, and desktop
- ⚡ **Zero dependencies** — pure HTML/CSS/JS, no framework, no build step
- 🚀 **Static site** — hosted on GitHub Pages, loads in milliseconds

---

## Tech Stack

- Pure **HTML + CSS + JS** — no React, no Vue, no build tools
- **GitHub Pages** — zero-cost hosting, zero-config deployment
- **Google Fonts** — Inter + JetBrains Mono
- Generative SVG art thumbnails — seeded procedural art per prompt card
- CSS custom properties for theming — 6 accent themes, instant switching

## Local Development

No build step needed. Just clone and open.

```bash
git clone https://github.com/echobash/promptflix.git
cd promptflix
open index.html
# or
npx serve .
```

## Contributing

Want to add a prompt? Found a dead link? Open an issue or PR.

### Submit a prompt

1. [Open an issue](https://github.com/echobash/promptflix/issues/new) with the label `prompt-submission`
2. Include: **title**, **category**, **the prompt text** (with `[BRACKETS]` for variables), and **which AI tools it works with**
3. Keep it practical — prompts that get real results, not demo-ware
